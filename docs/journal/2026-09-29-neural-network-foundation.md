# Neural network foundation

## Goal

Move to the neural architecture without committing to paid compute or a costly
self-play system. Build and test the smallest reusable policy/value component
first.

## What changed

- Added a 4-block, 32-channel residual policy/value network with 133,100
  parameters.
- Added mover-relative feature encoding plus an absolute Black-to-move plane.
- Added legal-action masking and consistent D4 feature/policy transformations.
- Added a compiled supervised update and a versioned parameter checkpoint.
- Added tests for shapes, encoding, masking, transformations, checkpoint
  reproduction, and real gradient-based loss reduction.
- Added a script that overfits the full model on the eight tactical fixtures.

## Bug caught by the overfit test

The first value head applied LayerNorm after projecting every point to one
channel. LayerNorm over a singleton channel always returns zero, which removed
all board information from the head. Expanding that projection to four channels
fixed the issue. A shape-only test would not have found it.

## Result

With seed 0, Adam at 0.003, and 200 full-batch updates on CPU:

- total loss: 5.8728 to 0.3472;
- policy loss: 5.3100 to 0.3470;
- value loss: 0.5628 to 0.0002;
- wall time: approximately 5.2 seconds;
- purchased compute: $0.

The policy result is effectively optimal for these targets. Four fixtures have
two acceptable moves with equal target probability, giving a theoretical
average entropy floor of about 0.3466. The value targets were synthetic values
from -1 to 1, used only to test plumbing; they do not measure value quality.

## Decision

Keep this architecture small. The next step is a reproducible complete-game
dataset generated by the existing classical agents, with train/validation split
by game and real outcome labels. Do not start AlphaZero self-play yet.
